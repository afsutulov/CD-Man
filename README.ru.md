# CD-Man 2

[English](README.md) | Русский

Порт **CD-Man 2.0** — классической аркады с лабиринтами от Creative Dimensions (1992) — на Go для **Windows, Linux и macOS**. Собирайте все точки, избегайте врагов, используйте энергетические заряды для контратаки и проходите пять миров с оригинальной графикой и звуком в стиле PC Speaker.

Игра работает в собственном окне. Установка DOS или отдельного DOS-эмулятора не требуется. Все игровые ресурсы встроены в исполняемый файл.

## Возможности

- Пять миров с оригинальной графикой, лабиринтами, врагами и бонусами.
- **One** — один игрок, **Two** — два игрока по очереди, **Double** — два игрока одновременно на одном компьютере.
- Оригинальное меню, выбор скорости, встроенная демонстрация, справка, Top-10 и статистика.
- Управление клавиатурой и джойстиком.
- Полноэкранный запуск; переход в оконный режим через **Alt+Enter**.
- Чёткая пиксельная графика, область изображения 4:3 и двойная буферизация в Windows.
- Запуск игры без первоначального запроса идентификации.
- Сохранение рекордов и данных демонстрации в папке настроек пользователя.

## Требования

| Платформа | Для сборки | Для запуска |
| --- | --- | --- |
| Windows x64 / ARM64 | Go 1.22+; интернет при первом запуске инструмента включения иконки | Системные библиотеки Windows; SDL2 и компилятор C не нужны |
| Linux | Go 1.22+, компилятор C, включённый cgo | Библиотека SDL2 и графическая сессия |
| macOS Intel / Apple Silicon | Go 1.22+, Xcode Command Line Tools, включённый cgo | Библиотека SDL2 |

В Linux и macOS SDL2 загружается динамически: заголовочные файлы для разработки не требуются, а SDL3 не заменяет SDL2. В macOS загрузчик также проверяет `/opt/homebrew/lib`, `/usr/local/lib` и `/Library/Frameworks/SDL2.framework/SDL2`.

Go нужен только для сборки, а не для запуска готового релиза. Версии для Linux и macOS собирайте в соответствующей операционной системе с установленными компилятором и SDL2.

## Сборка и запуск

Клонируйте репозиторий или распакуйте архив исходников. Выполняйте команды сборки из корня проекта, где находятся `main.go`, `go.mod` и `cdman2.ico`:

```sh
git clone https://github.com/afsutulov/CD-Man2.git
cd CD-Man2
```

### Windows: сборка с иконкой игры

В корне находится `cdman2.ico` с прозрачностью и изображениями размером 16, 24, 32, 48, 64, 128 и 256 пикселей. Go не включает ICO автоматически: сначала создайте объект ресурсов Windows, затем соберите **пакет**.

Выполните в **PowerShell** на Windows:

```powershell
$arch = go env GOARCH
$env:CGO_ENABLED = "0"
go run github.com/akavel/rsrc@v0.10.2 -arch $arch -ico icon.ico -o "rsrc_windows_$arch.syso"
go build -trimpath -ldflags="-s -w -H=windowsgui" -o CD-Man2.exe .
.\CD-Man2.exe
```

Инструмент ресурсов запускается с явно указанной версией и не добавляет зависимость в `go.mod`. Файл `.syso` должен находиться рядом с `main.go`. Go автоматически включает ресурс, соответствующий целевой платформе и архитектуре. Собирайте **`.`**, а не `main.go`, чтобы ресурс вошёл в сборку. Флаг `-H=windowsgui` убирает отдельное окно консоли.

Для сборки Windows ARM64 на компьютере с Windows x64 сначала создайте ресурс, а затем измените целевую архитектуру:

```powershell
go run github.com/akavel/rsrc@v0.10.2 -arch arm64 -ico cdman2.ico -o rsrc_windows_arm64.syso
$env:GOARCH = "arm64"
go build -trimpath -ldflags="-s -w -H=windowsgui" -o CD-Man2-arm64.exe .
Remove-Item Env:GOARCH
```

Для сборки Windows из Linux или macOS сначала запустите генератор ресурсов в системе сборки, затем задайте целевую платформу только для команды компиляции:

```sh
go run github.com/akavel/rsrc@v0.10.2 -arch amd64 -ico cdman2.ico -o rsrc_windows_amd64.syso
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H=windowsgui" -o CD-Man2.exe .
```

Созданный `.syso` — результат подготовки к сборке. Можно оставить его для следующих сборок либо удалить после компиляции и создать заново в следующий раз. После изменения `cdman2.ico` ресурс нужно пересоздать. Суффиксы платформы и архитектуры исключают подключение этих ресурсов при сборке Linux/macOS или для другого процессора.

Встроенная иконка отображается у исполняемого файла Windows в Проводнике и ярлыках. Linux и macOS не используют ресурсы Windows ICO для иконок исполняемых файлов: там требуется файл запуска или пакет приложения соответствующей платформы.

### Linux

Установите Go, компилятор C и библиотеку SDL2 средствами своего дистрибутива, затем выполните:

```sh
CGO_ENABLED=1 go build -trimpath -ldflags="-s -w" -o CD-Man2 .
./CD-Man2
```

### macOS

Установите Go, SDL2 и Xcode Command Line Tools. Если инструменты компилятора отсутствуют, выполните `xcode-select --install`. При использовании Homebrew установите SDL2 командой `brew install sdl2`.

```sh
CGO_ENABLED=1 go build -trimpath -ldflags="-s -w" -o CD-Man2 .
./CD-Man2
```

Получится исполняемый файл для архитектуры установленного инструментария Go, а не пакет macOS `.app`.

## Управление и меню

| Действие | Управление |
| --- | --- |
| Открыть меню с начального экрана | Пробел |
| Перейти между колонками и пунктами меню | Стрелки |
| Выбрать выделенный пункт | Enter |
| Движение с клавиатуры в режиме One / Two | Стрелки |
| Движение игрока 1 в режиме Double | W вверх, A влево, D вправо, Z или X вниз |
| Движение игрока 2 в режиме Double | Стрелки |
| Вернуться в меню во время игры | Esc |
| Продолжить текущую игру | GAME → Continue |
| Переключить полноэкранный / оконный режим | Alt+Enter |
| Переключить Top-10 и статистику | Пробел на странице рекордов / статистики |
| Завершить игру через меню | GAME → Quit |
| Немедленно выйти с риском потери несохранённых рекордов | Ctrl+Q |

В **PLAYER** выбирается режим игроков, в **SPEED** — скорость, в **SOUND** — звук. **GAME → Control** переключает управление клавиатурой или джойстиком; адаптер платформы использует первый доступный джойстик. **SEE → Info** открывает оригинальную англоязычную справку, **SEE → Demo** запускает демонстрацию, **SEE → Position** показывает текущее положение в игре.

Чтобы сохранить рекорды, завершайте игру через **GAME → Quit**. Возврат в меню по Esc сохраняет текущую игру только до закрытия приложения.

## Сохранённые данные

Приложение использует `os.UserConfigDir()` и хранит `HIGHSC.CDM` и `DEMO.CDM` в подпапке `CDMan-Go`:

| Платформа | Папка по умолчанию |
| --- | --- |
| Windows | `%APPDATA%\CDMan-Go` |
| Linux | `$XDG_CONFIG_HOME/CDMan-Go` или `~/.config/CDMan-Go` |
| macOS | `~/Library/Application Support/CDMan-Go` |

Существующие файлы используются вместо встроенных копий. Замена исполняемого файла не удаляет сохранённые данные. Папка сохранения должна быть доступна для записи.

Закрытие окна не сохраняет прохождение: **Continue** продолжает игру в текущем сеансе, а не после повторного запуска приложения.

## Структура исходников и проверки

| Путь | Назначение |
| --- | --- |
| `main.go` | Точка входа и хранение сохраняемых данных |
| `internal/game/` | Перенесённая игровая логика, состояние, графика, звук и тесты |
| `internal/assets/` | Встроенное начальное состояние и оригинальные ресурсы `.CDM` |
| `internal/platform/` | Адаптер Win32/GDI/WinMM для Windows; SDL2/cgo для Linux и macOS |
| `cdman2.ico` | Иконка приложения Windows |
| `LICENSE-font.txt` | Лицензия встроенного растрового шрифта |

Запуск существующих проверок из корня проекта:

```sh
go test ./...
```

Тесты проверяют байтовую арифметику, точные хеши пикселей всех 17 графических ресурсов и сценарий меню → запуск → движение → пауза → продолжение. Окна, звук и ввод также нужно проверить на каждой поддерживаемой операционной системе.
